Think of distribution graphs as the ultimate map for your data points, showing exactly how they like to spread out and mingle across a range of values. Instead of staring at a boring wall of numbers, these charts instantly reveal how often things actually happen, where the "center of gravity" sits (your trusty mean and median), how chaotic the variance is, and who the weird outliers are. To map this out, we have a whole toolbox of visual options: box-and-whisker plots, candlestick charts, histograms, pyramid charts, raincloud plots, ridgeline plots, and statistical uncertainty. We are going to break down each chart type below using the exact same dataset from our previous comparison tables. We are going to audition each of them using data from Table 1.

Box-and-whisker

If you want to see data spread and skewness at a glance, this is your go-to chart. Picture a neat little box with two lines, the whiskers, stretching out from the sides to show you exactly what your data is up to. The center line represents the median, splitting your data right down the middle, while the cozy boundary of the box packs in the middle 50% of your total data. Stretching out from there, the whiskers act as arms that reach to a standard length of 1.5 times your interquartile range to capture the rest of the normal data pool. Anything sitting completely outside those whiskers is officially an oddball outlier. For instance, if you take a peek at Figure 1, item C clearly has a rogue outlier photobombing the chart all the way up near 30.

Candlestick Chart

While these usually pop up when people are stressing over financial data, you can think of these charts as the slightly fancier cousins of the box-and-whisker plot. The "wicks" stretching out from the top and bottom show you the absolute highest and lowest values achieved during that time frame. Meanwhile, the main body of the candle represents your opening and closing values, with a light or white candle acting as a green light to show that the closing value finished higher than the opening one. If you take a peek at Figure 2, you can see that the lowest Count value for each of the three items either occured at the beginning or end of the year since there is no line extending below the box.

R Script Execution & Plot Generation Architecture

The following optimized ggplot2 framework generates a clean, warning-free candlestick chart by explicitly mapping data point variables, standardizing linear tracking scales up to a 400-count threshold ceiling, and purging default chart grid lines to maximize executive clarity.

df1$M1 <- match(df1$Month, month.abb) ohlc <- df1 %>% group_by(Item) %>% summarise( open1 = Count[M1 == 1], high1 = max(Count), low1 = min(Count), close1 = Count[M1 == 12], .groups = "drop" ) %>% mutate(Item = factor(Item, levels = c("A", "B", "C"))) gray_palette <- c( "A" = "#D3D3D3", # Light grey "B" = "#808080", # Grey "C" = "#404040" # Dark grey ) plot2 <- ggplot(ohlc, aes(x = Item)) + geom_linerange(aes(ymin = low1, ymax = high1), color = "black", linewidth = 0.8) + geom_rect(aes(xmin = as.numeric(Item) - 0.25, xmax = as.numeric(Item) + 0.25, ymin = pmin(open1, close1), ymax = pmax(open1, close1), fill = Item), color = "black") + scale_fill_manual(values = gray_palette) + labs(x = NULL, y = NULL) + theme(plot.title = element_blank(), axis.title.x = element_blank(), axis.title.y = element_blank(), axis.ticks = element_blank(), axis.text.x = element_text(hjust = 0.5, face = "bold", color = "black", size = 20), axis.text.y = element_text(angle = 0, vjust = 0.5, face = "bold", color = "black", size = 20), legend.position = "none", panel.background = element_blank(), panel.grid.major.y = element_blank()) plot2

Histogram

If you want to see exactly how your data aggregates, a histogram is your perfect match. This chart takes all your chaotic data points and neatly organizes them into specific "bins" or ranges, using connected bars to show you how often your data chooses to hang out in each bucket. It is a fantastic tool for instantly revealing patterns like center, spread, and overall shape. Looking closely at Figure 3, none of the items have a beautiful, symmetric normal distribution, with all of the Items being slightly skewed to the right with a large variance.

R Script Execution & Plot Generation Architecture

The following optimized ggplot2 framework generates a clean, warning-free histogram by explicitly mapping data point variables, standardizing linear tracking scales up to a 400-count threshold ceiling, and purging default chart grid lines to maximize executive clarity.

b_width <- 2 # bin width plot3 <- ggplot(df1, aes(x = Count)) + geom_histogram(aes(fill = Item), binwidth = b_width) + scale_fill_manual(values = gray_palette) + stat_function( fun = function(x, mean, sd, n) { dnorm(x, mean = mean, sd = sd) * b_width * n }, args = list( mean = mean(df1$Count), sd = sd(df1$Count), n = 12 ), color = "black", linewidth = 1.2 ) + facet_wrap(~ Item, strip.position = "bottom") + labs(x = NULL, y = NULL) + theme(plot.title = element_blank(), axis.title.x = element_blank(), axis.title.y = element_blank(), axis.ticks = element_blank(), axis.text.x = element_text(hjust = 1, face = "bold", color = "black", size = 15), axis.text.y = element_blank(), axis.ticks.y = element_blank(), panel.spacing.y = unit(0, "lines"), strip.text.x.bottom = element_text(size = 20, angle = 0, hjust = .5, face = "bold"), strip.background.x = element_blank(), strip.placement = "outside", legend.position = "none", panel.background = element_blank()) plot3

Pyramid Chart

Think of the pyramid chart as the ultimate data showdown. It is essentially a diverging bar graph that pits two different groups against each other, with the zero-axis sitting right in the middle like a referee. The bars stretch out to both the left and the right, which occasionally confuses people into thinking the left side represents negative values, but it is just a friendly side-by-side comparison. For a perfect example, take a look at Figure 4. Items A and B claim the left side while item C holds down the right, beautifully highlighting some completely unrelated data lengths for the months of June, July, and August.

R Script Execution & Plot Generation Architecture

The following optimized ggplot2 framework generates a clean, warning-free pyramid chart by explicitly mapping data point variables, standardizing linear tracking scales up to a 400-count threshold ceiling, and purging default chart grid lines to maximize executive clarity.

custom_order <- c("Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec") df1 <- df1 %>% mutate(Month = fct_relevel(Month, custom_order)) df2 <- df1 %>% filter(Item %in% c("A", "B")) %>% group_by(Month, Month1, M1) %>% summarise( Count = sum(Count), Rank = min(Rank), .groups = "drop" ) %>% mutate(Item = "AB") %>% bind_rows( df1 %>% filter(Item == "C") ) %>% arrange(M1, Item) %>% mutate(Index = row_number()) %>% select(Index, Item, Month, Month1, Count, Rank, M1) plot4 <- ggplot(df2, aes(x = fct_rev(Month), y = ifelse(Item == "AB", -Count, Count), fill = Item)) + geom_col(width = 0.7) + coord_flip() + scale_y_continuous( breaks = scales::breaks_pretty(n = 6), labels = abs ) + scale_fill_manual(values = c("AB" = "#969892", "C" = "#f0f0f0")) + geom_label(data=NULL, x=12, y=-15, label = "AB", linewidth=0, fontface = "bold", size=10, fill="white") + geom_label(data=NULL, x=12, y=10, label = "C", linewidth=0, fontface = "bold", size=10, fill="white") + labs(x = NULL, y = NULL) + # Removes both x and y axis titles theme(plot.title = element_blank(), axis.title.x = element_blank(), axis.title.y = element_blank(), axis.text.x = element_text(hjust = 1, face="bold", color="black", size=20), axis.text.y = element_text(angle=0, vjust = 1, face="bold", color="black", size=20), legend.position = "none", panel.background = element_blank()) plot4

Raincloud Plot

If you prefer to strip away the mystery and just let the raw numbers speak for themselves, the raincloud plot is your best friend. This layout simply puts the data on full display to highlight exactly how it chooses to scatter across three visual elements for each item: a smooth density cloud, a classic box-and-whisker summary, and the actual data points falling as rain directly underneath. Taking a gander at Figure 5, the math shows that item A is living its best life with a dense cloud and rain dots tightly packed around 17 (except for that lone spike up to 30), whereas the other two items are marching to their own beat with noticeably skewed distributions, stretched summary boxes, and distinct mid-year rain outliers.

Ridgeline Plot

If you want your data to look less like a spreadsheet and more like a majestic mountain range, the ridgeline plot is your go-to style. This chart cleverly stacks multiple density plots or histograms right on top of each other, making it incredibly easy to compare how a numeric variable behaves across completely different categories. Looking at Figure 6, you can see this landscape in action as it perfectly highlights the heavily skewed distributions of items A and B, while letting you see exactly how they stack up against the bi-modal peaks of item A.

Statistical Uncertainty

This is basically your data’s way of saying, "Give or take a little." To show this wiggle room visually, we dress up our charts with error bars, confidence intervals, fan graphs, or smooth color gradients that highlight just how much the data set likes to fluctuate. We can see a full parade of these safety nets in Figure 7, which tracks our quarterly counts. The top graph features error bars keeping item A in check, the middle graph wraps item B in a cozy confidence interval, and the bottom graph unleashes a dynamic fan graph to map out the possibilities for item C.
