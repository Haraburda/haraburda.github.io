Bar Graph

This chart is basically the “line‑up” of the chart world, with each category getting its own rectangular bar so you can instantly see who’s the big shot and who’s falling behind. These bars (or columns, if you’re feeling fancy) can stand tall or lay flat depending on how you set them up. In Figure 1, the bars are standing upright, loud and proud, and it’s pretty clear that item B is the overachiever of the group.

Bullet Graph

This is like the speedometer on your dashboard; it shows one number on a set scale and looks pretty cool doing it. But when it comes to actually understanding data, the bullet graph is the smarter, more practical cousin. It lays everything out in a clean, straight line so your eyes don’t have to work overtime. In Figure 3, you can see the monthly averages, with item B chilling comfortably in the middle range (20–29), right where the graph says, “Yep, that seems about right”.

Marimekko Graph

This chart, called a mosaic graph, is basically a stacked chart that decided to go 2‑D and show off. Instead of just stacking things up, it also stretches the columns wider or narrower to show how different categories relate to each other. In Figure 6, item B is clearly the star of the 20–29 range, taking up more space than the other two items and making sure everyone notices.

R Script Execution & Plot Generation Architecture

The following optimized ggplot2 framework generates a clean, warning-free Marimekko graph by explicitly mapping data point variables, standardizing linear tracking scales up to a 400-count threshold ceiling, and purging default chart grid lines to maximize executive clarity.

# Categorize data entries into three specified group ranges df_grouped <- df1 %>% mutate(Group = case_when( Count >= 0 & Count <= 19 ~ "0-19", Count >= 20 & Count <= 29 ~ "20-29", Count >= 30 & Count <= 40 ~ "30-40" )) # Convert Group into a strict ordered factor layer for stacked alignment df_grouped$Group <- factor(df_grouped$Group, levels = c("30-40", "20-29", "0-19")) # Calculate the precise vertical middle points for Item C's labels # Placed at index 3.35 to clear the column width boundary (centered at 3.0) df_labels <- data.frame( X_Pos = c(3.35, 3.35, 3.35), Group = c("0-19", "20-29", "30-40"), Label_Y = c( 0.75 / 2, # Midpoint of 0-19 section (Y = 0.375) 0.75 + (0.0833 / 2), # Midpoint of 20-29 section (Y = 0.7917) 0.75 + 0.0833 + (0.1667 / 2) # Midpoint of 30-40 section (Y = 0.9167) ), Label_Text = c("0-19", "20-29", "30-40") ) plot6 <- ggplot(df_grouped, aes(x = Item, fill = Group)) + geom_bar(position = "fill", width = 0.6, color = "#FFFFFF", linewidth = 0.5) + scale_fill_manual(values = c( "0-19" = "#E0E0E0", # Light grey "20-29" = "#A0A0A0", # Grey "30-40" = "#707070" # Dark grey )) + scale_x_discrete(expand = expansion(mult = c(0.2, 0.6))) + scale_y_continuous(labels = scales::percent_format(), expand = expansion(mult = c(0, 0.05))) + geom_text(data = df_labels, aes(x = X_Pos, y = Label_Y, label = Label_Text), inherit.aes = FALSE, color = "#000000", fontface = "bold", size = 4.5, hjust = 0, vjust = 0.5) + labs(x = NULL, y = NULL) + theme(plot.title = element_blank(), axis.title.x = element_blank(), axis.title.y = element_blank(), axis.text.x = element_text(hjust = 0.5, face = "bold", color = "black", size = 15), axis.text.y = element_text(angle = 0, vjust = 0.5, face = "bold", color = "black", size = 15), legend.position = "none", panel.background = element_blank(), axis.line.x = element_blank(), axis.line.y = element_blank(), axis.ticks = element_blank()) plot6

Sankey

This is like an air‑traffic controller of charts as it shows you exactly where everything is flowing and how much of it is moving around. The thicker the connecting lines (called links), the bigger the flow. It’s perfect for tracking how resources like hours, materials, or general chaos move through different stages, known as nodes. In Figure 7, you can follow the journey as each month sends its flow into items A and B, which then funnel into item C, before everything branches right back out into each month again. It’s basically a very organized data round‑trip.

Unit Graph

This is a waffle graph, which is what you get when data decides to express itself through tiny, evenly sized shapes. Think of it as a pixel‑art version of your dataset. In the 10×10 waffle setup shown in Figure 8, a solid 53% of the items land in the 10–19 range, which is noticeably higher than the counts in the other two ranges. Basically, that range is doing all the heavy lifting while the others are just along for the ride.

R Script Execution & Plot Generation Architecture

The following optimized ggplot2 framework generates a clean, warning-free unit graph by explicitly mapping data point variables, standardizing linear tracking scales up to a 400-count threshold ceiling, and purging default chart grid lines to maximize executive clarity.

remotes::install_github("liamgilbey/ggwaffle") group <- c("10-19","20-29","30-39") value <- c(53, 30, 17) waffle_matrix <- matrix(nrow=100, ncol=3) colnames(waffle_matrix) <- c("x", "y", "range") i <- 1; j <- 1; k <- 1 counter <- value[1] name1 <- group[1] for (l in 1:counter){ waffle_matrix[k,] <- c(i, j, name1) k <- k+1 if(i<10) {i <- i+1} else { i <-1 if(j<10) {j <- j+1} else (j <-1) } } counter <- value[2] name1 <- group[2] for (l in 1:counter){ waffle_matrix[k,] <- c(i, j, name1) k <- k+1 if(i<10) {i <- i+1} else { i <-1 if(j<10) {j <- j+1} else (j <-1) } } counter <- value[3] name1 <- group[3] for (l in 1:counter){ waffle_matrix[k,] <- c(i, j, name1) k <- k+1 if(i<10) {i <- i+1} else { i <-1 if(j<10) {j <- j+1} else (j <-1) } } df2 <- as.data.frame(waffle_matrix) %>% mutate(across(c(x, y), as.integer)) plot8 <- ggplot(df2, aes(x, y, fill = range)) + ggwaffle::geom_waffle() + scale_fill_manual(values = c("#cccccc", "#969892", "#3b444b")) + labs(x = NULL, y = NULL) + # Removes both x and y axis titles theme(plot.title = element_blank(), axis.title.x = element_blank(), axis.title.y = element_blank(), axis.text.x = element_blank(), axis.text.y = element_blank(), legend.position = "none", panel.background = element_blank()) + expand_limits(x = 12) text1 <- group[1]; text2 <- group[2]; text3 <- group[3] plot8 + geom_text(data = NULL, x = 11.5, y = 3, label = text1, size=6, fontface = "bold") + geom_text(data = NULL, x = 11.5, y = 7, label = text2, size=6, fontface = "bold") + geom_text(data = NULL, x = 11.5, y = 9.5, label = text3, size=6, fontface = "bold") + coord_cartesian(clip = "off")

Waterfall Graph

This is basically the storytelling bar graph. It walks you through how an initial value gets nudged up by the good stuff, dragged down by the not‑so‑good stuff, and finally lands on a grand total. In Figure 9, you can see items A and B adding to the pile, item C subtracting from it, and the whole thing settling at a neat net total of 307 counts. It’s like watching your data balance its checkbook.

R Script Execution & Plot Generation Architecture

The following optimized ggplot2 framework generates a clean, warning-free waterfall graph by explicitly mapping data point variables, standardizing linear tracking scales up to a 400-count threshold ceiling, and purging default chart grid lines to maximize executive clarity.

Items <- c("A", "B", "C") Amount <- c(216, 331, -240) df_water <- data.frame(Items, Amount) color_vector <- c("#f0f0f0", "#e0e0e0") waterfall(df_water, calc_total = TRUE, fill_by_sign = FALSE, # Disable automatic sign coloring fill_colours = color_vector, # Apply custom colors total_axis_text = "Net", total_rect_color = "grey", rect_text_size = 3, draw_lines = FALSE, draw_axis.x = "none") + theme(plot.title = element_blank(), axis.title.x = element_blank(), axis.title.y = element_blank(), axis.text.x = element_text(hjust = 0.5, face="bold", color="black", size=20), axis.text.y = element_text(angle=0, vjust = 1, face="bold", color="black", size=20), axis.ticks = element_blank(), legend.position = "none", panel.background = element_blank())
